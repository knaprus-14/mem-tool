# Проверка alpha.35 — названия и повторные упоминания тем

Дата: 2026-09-11. Исправление предварительного релиза 1.71.0.

В кластере «ВПВ» были четыре пустых обозначения темы из разных фрагментов,
определение с таким же заголовком, два утверждения и одно ограничение.
Alpha.34 объединила их в группу, но продолжала показывать повторные обозначения
отдельными узлами. Проверенная расшифровка в тексте источника на странице 2:
«внутренний противопожарный водопровод (ВПВ)».

## Изменение

- Пустые обозначения одной темы, созданные моделью в одной редакции документа
  с одинаковым статусом, сворачиваются в один элемент внутри кластера.
  Содержательные темы, определения, требования и ручные записи не объединяются.
- Явные расшифровки сокращений извлекаются из текста источника по форме
  «полное название (сокращение)», с проверкой начальных букв и привязкой к
  документу/редакции. Неоднозначное или неизвестное сокращение не раскрывается
  и не используется для сворачивания повторов.
- Полное имя используется в названии кластера, графе, карточках, поиске и
  инспекторе. Определения имеют отдельный префикс. Длинные подписи переносятся
  на несколько строк; нажатие на подпись открывает узел.
- В небольшом кластере с одной темой знания располагаются рядом с её общим
  узлом. Исходные связи направляются к общему обозначению без изменения ID,
  типа, статуса или доказательств связи.
- Щелчок по общей теме открывает перечень исходных упоминаний. «Все исходные
  записи» возвращает отдельное отображение каждого из них. Редактирование
  и проверка продолжают обращаться к конкретным исходным объектам.
- Запрос к модели уточнён: названия должны раскрывать предмет утверждения,
  определения обозначаются явно, расшифровки берутся только из evidence.

## Проверки

1. `go test ./... -count=1 -timeout=300s` — успешно, пакет mem 64,993 с.
2. `go vet ./...` — успешно.
3. После завершающих правок поиска/заголовка выполнены тесты HTML, тем и видов:
   `go test ./pkg/mem -run 'TestKnowledge(MapHTML|Topics|MapLayout|MapView)'`.
4. Node-тесты с приватным снимком — 10/10. Проверены сохранность разных
   требований, неоднозначные сокращения, разные документы и редакции, разные
   статусы, отсутствие источника, пустые и большие графы, исходные рёбра.
5. Во встроенном браузере на копии корпуса: пять элементов и четыре связи
   вместо восьми отдельных записей; переключение 5 → 8 → 5; нажатие по длинной
   подписи; четыре упоминания со страниц 3, 5, 11, 20; открытие цитаты страницы 5;
   карточки темы; поиск по полному названию; автоматическое открытие примера.
   В журнале браузера ошибок JavaScript нет. Ширина проверки графа — 1440.
6. `git diff --check` — успешно, предупреждения только о CRLF/LF.

Использован снимок alpha.34 с 635 узлами и 960 связями, скопированный через
SQLite backup в `build/web-alpha/alpha35/repro`. Оригинальная база не изменялась.
В проверенном кластере сохраняются восемь исходных записей, на экране пять
элементов: общий узел темы, определение, два утверждения и ограничение.
Повторы сворачиваются только при просмотре. Связи и цитаты в БД не переписаны.

Предпросмотр всего корпуса: `build/web-alpha/alpha35/preview/index.html`.
Пример с открытым кластером ВПВ: `build/web-alpha/alpha35/preview/vpv.html`.
Оба файла содержат приватный снимок и не предназначены для публикации.

Новый живой запуск модели не выполнялся. Исправление не пересказывает прежние
утверждения и не исправляет автоматически все неудачные содержательные
заголовки. Например, сохранённый заголовок «Возможности ВПВ» остаётся прежним.
Это проверка конкретного исправления повторов и расшифровки, а не доказательство
полноты и правильности извлечения всего документа.

`Deployment target ... is not writable`, `Access to the path ... is denied`.
