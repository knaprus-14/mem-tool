# Качество графа: первый этап

Рабочая база: согласованный пользователем каталог `E:\temp\mem-test4`.
Оригинал открывается только для чтения. Согласованный снимок SQLite находится
в игнорируемом `build/web-alpha/alpha28/real-corpus/.mem/store.db`.
Проверка целостности снимка: `ok`; 501 фрагмент, 1030 узлов, 890 связей.

План и критерий завершения:

- [x] Добавить проверяемые цитатами условия, исключения и ограничения в извлечение.
- [x] Устранить ложные совпадения оценки при изменении отрицаний и чисел;
  добавить обязательные смысловые фрагменты в размеченный эталон.
- [x] Добавить широкое окно сопоставления узла или связи с выдержкой документа
  и обратный переход к объектам, использующим тот же фрагмент.
- [x] Проверить на снимке реальных документов и регрессионных примерах;
  отделить результаты выборки от оценки качества всего корпуса.
- [x] Обновить версию и документацию, выполнить проверки и сборку трёх команд;

Этот этап не переизвлекает и не переписывает граф пользователя автоматически.
Проверка наличия цитаты не доказывает правильность трактовки: новые узлы остаются
черновиками. Последующие этапы: графовый поиск для RAG, загрузка больших графов
по области интереса, адаптивные маршруты изучения.

к каталогу; три проверенных бинарных файла сохранены в staging проекта.
