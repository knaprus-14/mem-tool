# Проверка истории и корзины заметок 1.71.0-alpha.7

Дата: 9 сентября 2026 года. Продолжение общей веб-оболочки mem-tool.

## Реализовано

- История состояний до/после изменений через веб; исходное состояние существующей
  CLI-заметки сохраняется перед веб-правкой. Повтор одинакового исходного состояния
  не добавляет лишнюю запись «До изменения».
- Просмотр текста версии, восстановление прежнего состояния; текущая сохранённая
  запись остаётся в истории. Несохранённая форма закрывается с явным пояснением.
- Перемещение ручной заметки в корзину, отдельный список и возврат с прежним ID,
  текстом, тегами, важностью, метаданными вектора и самим вектором без вызова модели.
- Удалённые записи исключены из обычной библиотеки, поиска и кэша CLI.
- Запись, история, корзина и квитанция попытки изменяются одной транзакцией.
  Устаревшая форма, подменённый снимок и занятый ID отклоняются; повтор подтверждённой
  операции возвращает квитанцию и не повторяет изменение после более поздних действий.
- Строгое API с проверкой владельца/CSRF, общими лимитами запросов и 15-секундным
  контекстом изменения. История и корзина читаются по 30 строк; в ответах нет векторов,
  адресов провайдеров, путей источников и служебных полей.
- Чтение не создаёт таблиц. При записи добавляются `web_note_history` и
  `web_note_trash`; существующий журнал `web_note_writes` используется повторно.

## Ограничения

История ограничена веб-операциями. Промежуточные CLI-правки не журналируются;
CLI-удаление не отправляет запись в корзину. Документные фрагменты этим API не
редактируются. До 10000 состояний / 256 МиБ JSON-снимков на базу, до 2 МиБ на снимок,
до 100000 квитанций; при лимите новая операция отменяется целиком. Автоочистки и
безвозвратного удаления через веб нет. Backup должен включать всю БД с журналами.
Дата восстановленной записи обновляется; вектор прежней модели может оказаться
несовместимым с текущим поиском по смыслу. Пересчёт индекса и интеграция библиотеки
карт в общую оболочку остаются последующими этапами. Старый интерфейс карт сохранён.
