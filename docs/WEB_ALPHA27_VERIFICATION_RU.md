# Проверка 1.71.0-alpha.27

Дата: 10 сентября 2026 года. Исходные пользовательские изменения и базы сохранены.
Работа велась в текущем checkout; commit/push/размещение на VDS не выполнялись.

## Автоматические проверки

- Полный `go test ./... -count=1 -timeout=300s` прошёл, в том числе повторно
  в штатном Windows-сборщике после последних изменений производственного кода.
- `go vet ./...` прошёл. `gofmt -l` затронутых пакетов не выявил файлов;
  `git diff --check` прошёл (только уведомления Git о нормализации LF/CRLF).
- 26 JavaScript-сценариев прошли: Node использовался с
  `--test --test-isolation=none`, поскольку обычный режим с дочерними процессами
  был запрещён средой (`spawn EPERM`). Проверен синтаксис новых модулей.
- Корзина карт: конфликт ревизии, чужая квитанция, повтор запроса удаления
  после восстановления, новые циклы удаления/восстановления.
- Управляемые вложения: запись/чтение, контрольная сумма, старые ревизии,
  запрет имени с путём. Метаданные: сохранность текста, происхождения и векторов.
- Переразбиение: реальный Markdown через тестовую модель embeddings,
  изменение числа фрагментов, сохранение идентичности документа и истории,
  отмена, чужой владелец, продолжение и восстановление прерванного задания.
- Дополнительные интеграционные тесты очереди графа прошли отдельно после сборки:
  ответ тестовой модели опубликован как узел с текущим подтверждением;
  поиск дублей сохраняет результат; анализ сохраняет отказ от вывода при
  недостаточных подтверждениях. Производственный код после сборки не менялся.
- Общий граф: чужой владелец получает 404, анонимный клиент — 401;
  проверяются mount и дополнительные полномочия изменяющих запросов.
- Хранение: при превышении лимита запись и создание базы получают 507,
  чтение/отчёты доступны, доступ чужого владельца и обход CSRF запрещены.
  Создание снимка карты не ошибочно приравнивается к чтению истории документа.
- Перенос: ZIP со снимком SQLite, очистка секретов/подключений, проверка путей,
  запрет существующего назначения. После удаления прежнего PDF источник
  открывается из новой базы, включая старый редактор. Повторный перенос проходит.
  Проверен список моделей, разрешённых сервером.
- PowerShell: проверка предварительного доступа, восстановления при сбое,
  транзакции установки и блокировки второго exe прошли на отдельных фикстурах.
  Четыре Python-теста резервного копирования прошли.

## Проверка исполняемого файла и браузера

Итоговый Windows mem.exe работал на 127.0.0.1:18797; модель embeddings —
изолированный локальный обработчик на 127.0.0.1:18927. Пользовательские модели,
корпусы и два установленных процесса mem не затрагивались.

Через интерфейс проверены:

1. Создание новой базы и загрузка раздела обслуживания с размерами хранения.
2. Отчёт покрытия и отображение его структуры.
3. Создание карты, удаление в корзину, восстановление, возврат в библиотеку.
   Итоговая карта имеет ревизию 3 и пустой маркер удаления.
4. Изменение названия, тега и важности фрагмента; новый текст свойств виден
   в списке документа после сохранения.
5. Изменение размера фрагмента с 1000 до 200 и перекрытия со 100 до 0,
   запуск переразбиения с подтверждением, завершение 1/1. SQLite подтверждает
   14 фрагментов вместо прежних 3.
6. Открытие расширенного графа в общей сессии. Сохранение представления
   «Проверочный вид» прошло через его API; запись подтверждена в SQLite.
   Консоль браузера не сообщила JavaScript-ошибок.
7. Отдельный HTTP-экспорт из этой же базы: 200, ZIP 23 422 байта,
   четыре файла, один оригинал, ноль пропущенных источников.

Попытка загрузить синтетическое вложение через file chooser была отклонена
автоматической политикой браузера: отказ разрешения загрузки на localhost.
Повтор, другой браузер и обход через HTTP не выполнялись. Поэтому браузерная
загрузка вложений и обратный импорт ZIP не заявляются проверенными;
соответствующие операции ядра проверены отдельно до отказа.

Временные вкладки закрыты. Остановлены только собственные сервер и модель
(PID 15912 и 21636), после проверки их исполняемых путей и времени запуска.
Фикстуры и экспорт оставлены в `build/web-alpha/alpha27/fixture`.

## Границы результата

Функции и ограничения описаны в [WEB_COMPLETION_RU.md](WEB_COMPLETION_RU.md).
Не проверялись реальные облачные/локальные AI-модели, полномасштабная нагрузка,
Linux runtime, nginx/HTTPS/systemd на VDS и браузерные загрузки после отказа
политики. Логические удаления сохраняют историю и не освобождают всё место;
пределы хранения являются проверками допуска, а не квотами файловой системы.
