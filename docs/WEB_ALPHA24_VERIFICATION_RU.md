# Проверка 1.71.0-alpha.24 — узел и исходный документ

Дата: 10 сентября 2026 года.

## Результат

В панели выбранного узла добавлена кнопка «Сверить с документом».
Большое окно показывает текст узла слева, извлечённую страницу справа.
Подтверждение выделено, прокрутка подводит к нему; список переключает источники.
PDF открывается отдельной вкладкой с #page=N, исходный файл не изменяется.
В текстовом сравнении подсвечивается прикреплённый фрагмент, в PDF — только
переход к физической странице, без автоматического выделения пункта.

API принимает идентификаторы базы, карты, узла, прикреплённого источника и ревизию.
Путь клиента не принимается. Текст ограничен 500 фрагментами / 2 МиБ на страницу;
без страниц выбираются соседние блоки. При устаревшей привязке остаётся сохранённая
цитата. Выдаётся только PDF с сохранённым SHA-256, в виде проверенного частного
снимка до 64 МиБ. Серверный режим использует os.Root внутри каталога базы.

## Автоматическая проверка

- Полный `go test ./... -count=1 -timeout=300s` штатного deploy/windows.ps1 прошёл.
- `go vet ./...`, синтаксическая проверка всех JS assets — успешно.
- 26 JS-сценариев: прежние навигация, удаление, разделитель, прогресс; новые
  сопоставление, буквальный текст, смена источника и отбрасывание запоздалых ответов.
- Go: точная привязка к узлу и пути, выделение цитаты, конфликт ревизии,
  изменённый файл, удалённые фрагменты, документ без страниц, старый источник без
  отпечатка, отклонение пути вне серверной базы. Дополнительный тест без страницы
  выполнен после полного прогона; после сборки менялись только тест и документация.
- HTTP: владелец / чужой пользователь / анонимный запрос, отсутствие ревизии,
  отсутствие приватных путей в ответах, PDF GET/HEAD/Range 206 и sandbox CSP.

## Браузер

Проверен итоговый бинарник на localhost:18794 с изолированной копией тестовой
базы и синтетическим двухстраничным PDF. При выборе «Проверенная тема» показан
текст узла и выделенное подтверждение. Окно 1250×688 в viewport 1280×720,
области читаемы и не перекрываются. Ссылка открыла вкладку встроенного PDF
просмотрщика на странице 1 из 2; отдельно проверена загрузка этого же URL.
Ошибок в журнале интерфейса и stderr сервера нет.

Адаптивные стили для ширины до 750 px добавлены. Мобильная визуальная проверка
не подтверждена: viewport override среды не изменил фактическую ширину 1280 px.
Проверка реальных документов АУП-1 и их точности извлечения в этот прогон не входила.
Пользовательские документы, карты, модель и работающий процесс не изменялись.
Тестовый сервер и его вкладки закрыты, настройка viewport сброшена.

## Сборка и установка

Все три Windows/amd64 бинарника собраны штатным скриптом и сообщают alpha.24.
Артефакты: `build/web-alpha/alpha24/windows-amd64`; SHA256.json сверён со stage.

Установка в C:\Users\ZMII\bin заблокирована на проверке записи:
Access denied для `.mem-deploy-probe-572c7bf644294e949ea0304dd5124c1a`.
Сборка с целью внутри проекта завершила тесты и компиляцию, но штатный скрипт
остановился перед копированием из-за пользовательского процесса mem:15300.
Из проверенного stage три файла скопированы в отдельный незанятый каталог
артефактов проекта, хеши совпали. Это подготовленная сборка, не установка в PATH.
Установленные mem, mem-index, mem-bot при проверке сообщали alpha.23.
Предупреждения Go о telemetry upload.token и module stat cache не помешали проверкам.

Для установки закройте работающий mem и выполните `./deploy/windows.ps1`
в обычном PowerShell из корня репозитория, затем запустите `mem gui` заново.
