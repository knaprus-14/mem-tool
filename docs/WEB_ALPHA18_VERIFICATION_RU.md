# Проверка 1.71.0-alpha.18 — 2026-09-09

## Реализовано

- Карточки из текста и структуры выбранной ветви, показ ответа, временные отметки
  изучения, переход к узлу с раскрытием пути, скачивание набора Markdown.
- Вопрос по актуальным прикреплённым фрагментам. Карта и подтверждения читаются
  в одном снимке SQLite; после ответа модели источники и ревизия проверяются ещё раз.
  Пути хранилища скрываются до построения запроса модели. Веб-ссылки не скачиваются.
- Сравнение двух карт одной базы, включая архивные: добавленные, удалённые,
  изменённые и перемещённые узлы. Общие алгоритмы CLI вынесены в функции без I/O.
- Предпросмотр разбиения примера текста и короткая проверка сохранённых моделей.
- Фоновое поколение векторов с сохранением прогресса, отменой, атомарным применением
  и возвратом прежних векторов. При смене записей/настроек старый результат
  применить нельзя. Перезапуск продолжает неподготовленные записи.

Текст, границы фрагментов, document IDs, revisions, anchors и история заметок
при применении поколения не меняются. Возврат не изменяет конфигурацию модели.
Новое поколение заменяет хранимую возможность возврата к предыдущему.
Лимиты: 20 000 записей / 64 МиБ текста с исходными векторами / 64 МиБ новых
векторов; один вызов embedding-модели до 100 секунд. Подготовка одного поколения
обрабатывает записи по очереди; индексный worker уступает другим базам после записи.

- Карты: совпадение сравнения с CLI, отсутствие записей при чтении,

на loopback. Реальные базы и модельные сервисы не использовались.

- Два фрагмента: до применения сохранялись `fixture-old`, размерность 2;
  после применения — `ollama / fixture-embedding`, размерность 3;
  после возврата — исходные метки и размерность 2. SQLite integrity_check: `ok`.
- Обе проверки моделей и предпросмотр разбиения выполнены через формы.
- На карте из 588 узлов: 587 учебных карточек, показ ответа, отметка изучения,
  переход к теме, прикрепление актуального фрагмента и ответ со ссылкой.
- Сравнение карты с собой: 588 неизменённых узлов. Сравнение новой учебной карты
  с исходной: 587 добавлено, 5 удалено, 1 изменён.
- На экране 390×844 диалог имел ширину 358 px и отступы 16 px;
  содержимое диалога: clientWidth=scrollWidth=341 px, без горизонтального переполнения.
- Журнал JavaScript: ошибок нет. Тестовые процессы остановлены, вкладка закрыта,
  размер браузера возвращён к 1280×720.

Модель была контролируемой заглушкой. Качество ответов реальной нейросети этим
не проверялось. Проверка браузера предшествовала последней правке подписи,
очистки запроса при закрытии окна и проверки нулевых векторов; после этих правок
повторены автоматические проверки и сборка.
