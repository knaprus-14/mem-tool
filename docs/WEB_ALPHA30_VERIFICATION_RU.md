# Проверки 1.71.0-alpha.30

Дата: 11.09.2026. Изменения внесены поверх существующей рабочей копии;
коммит, push и очистка чужих изменений не выполнялись.

## Автоматические проверки

- `go test ./... -count=1 -timeout=300s` — все пакеты прошли, включая SemVer.
- `go vet ./...` — пройдено.
- Все шесть файлов JavaScript-тестов `internal/webapp/*test.cjs` — 31 тест прошёл.
  Запуск каждого через `node <файл>`; отдельный процесс `node --test` блокировался
  средой с `spawn EPERM`, штатный встроенный node:test работает в текущем процессе.
- `node --check` для изменённых модулей — пройдено.
- `git diff --check` — пройдено; Git предупреждает о политике CRLF/LF.
- После расширения тестов отдельно повторены `TestWebGraphFullDocument*` и
  `TestGraphDocumentsAssetsServed`: все прошли.

Новые проверки ядра: три фрагмента проходят три порции при лимите один пакет,
сохраняют реальные узлы с актуальными evidence-ссылками; другой документ
не участвует. Проверены остановка после checkpoint, остановка после публикации
порции, продолжение без повторных вызовов модели, идемпотентный повтор отправки
и новый запуск по уже обработанному документу. Модель — локальный httptest,
пользовательские данные и внешние провайдеры не использовались.

JavaScript-проверки: полный режим с выбранным документом и редакцией настроек;
отсутствие документа; появление документа после завершения импорта; сохранение
request_id после потери ответа; поздний ответ другой базы; продолжение того же
сохранённого задания. HTTP-тест проверяет доступность нового модуля и точек входа.

## Браузер

Запущена отдельная база в `build/web-alpha/alpha30/browser-qa` и сервер состояния
в `build/web-alpha/alpha30/browser-state`. В браузере подтверждены открытие нового
раздела, отсутствие доступного запуска без документа, форма загрузки и её закрытие;
проверен внешний вид. Ошибок/предупреждений в консоли страницы не обнаружено.

Загрузка `manual.md` через браузер отклонена политикой разрешений Browser Use
(`user declined permission`). Обход не выполнялся. Поэтому полная цепочка
загрузка → импорт → граф в настоящем браузере НЕ подтверждена; её отдельные
механизмы проверены автоматическими тестами. Адаптивная проверка нового раздела
на узком экране не выполнялась. Тестовый браузер и оба вспомогательных сервера
закрыты. Настоящие документы/базы пользователя не изменялись.

При первоначальном CLI init тестовой базы store.db ещё отсутствовал, worker
сообщал `unable to open database file (14)`; после создания тестовой записи ошибка
исчезла. Это отдельный существующий сценарий регистрации пустой CLI-базы, не
исправленный данным изменением.

Все staging-файлы сообщают `1.71.0-alpha.30`. Это подготовленные артефакты,
не установка в PATH. Все три установленных бинарника проверены: остаются alpha.29.
Go дополнительно сообщал о запрете записи telemetry/upload.token и stat-cache;
тесты, vet и сборки завершились с кодом 0. Загрузка зависимостей отключена
через GOPROXY=off; использован доступный кэш компиляции в build/go-cache.

Для установки запустите в обычном PowerShell из репозитория:

```powershell
.\deploy\windows.ps1
mem version
mem-index version
mem-bot version
```

Скрипт повторно проверит доступ, выполнит обязательные тесты, staging-сборку,
установку и сравнение хешей. Работающие пользовательские процессы не останавливались.
