# Проверка 1.71.0-alpha.16 — переход из истории к узлу

Дата: 9 сентября 2026 года.

## Реализовано

История показывает текущее название затронутого узла. Для удалённого узла
показано последнее сохранённое название. Это не название из старого снимка;
интерфейс явно объясняет различие. Название добавлено в подтверждение отмены
и возврата, чтобы действие было легче сопоставить с нужной ветвью.

Кнопка «Показать узел» обновляет карту, раскрывает путь к узлу, выделяет его
и открывает текст при масштабе 100%. Состояние остальных ветвей сохраняется.
Переход не изменяет карту или историю. Если узел удалён после открытия истории,
появляется сообщение «Узел больше недоступен. Обновите историю карты».
После обновления истории у удалённого узла кнопки перехода нет.

GET истории возвращает дополнительные поля node_id, node_label, node_present.
Название читается из таблицы узлов, с обязательным совпадением map_id; узел
из другой карты не раскрывается. Название ограничено 512 символами, ID —
128 символами. Снимки, источники, векторы, авторы и комментарии не загружаются.
Схема базы, операции изменения карты и формат квитанций сохранены.

## Проверки

- Целевые тесты истории: текущее название после переименования отображается
  и у старого действия; удаление через undo сохраняет название, но снимает
  признак доступности; длинное название ограничивается 512 символами;
  ссылка на узел другой карты не раскрывает его ID или название.
- Все тесты WebMap и HTTP-оболочки прошли.
- Полный `go test ./... -count=1 -timeout=300s`, `go vet ./...`, проверка синтаксиса
  app.js, девять тестов map-layout и `git diff --check` — успешно.

Браузер проверен на отдельной копии искусственной карты alpha.15, исходно
586 активных узлов, ревизия 10 и девять записей истории:

1. История различает активные и удалённые узлы. У удалённых нет перехода.
2. Переход к скрытой «Новой ветви из браузера» закрыл историю, раскрыл путь,
   выделил узел и открыл текст. Масштаб — 100%, видно 26 из 586 узлов.
   Соседняя «Тема 2» осталась раскрытой. HTML в тексте показан буквально.
3. На экране 390×844 название удалённого узла видно в подтверждении возврата.
   Ширина страницы — 390 px, диалога — 360 px. «Не возвращать» закрывает
   подтверждение без изменения данных.
4. После этих действий полный SQLite iterdump совпал с исходной копией:
   навигация и закрытие подтверждения не изменили ни одной таблицы.
5. При открытой истории CLI удалил только тестовую «Новую ветвь из браузера».
   Переход из устаревшей строки сообщил, что узел недоступен. После обновления
   истории появилось обозначение удалённого узла, кнопка перехода отсутствует.
6. Ошибок JavaScript/CSP нет. Окно возвращено к 1280×720, тестовая вкладка
   и сервер закрыты. Пользовательский mem.exe не останавливался.

Итог базы: 585 активных узлов, ревизия 11, десять записей истории. Кроме признака
удаления тестового узла, CLI обновил служебное поле updated у него и восьми
соседних узлов. Содержимое остальных узлов и все квитанции совпадают с исходной
копией. `PRAGMA integrity_check = ok`.
