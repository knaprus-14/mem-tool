# Проверка 1.71.0-alpha.21 — спиннер создания карты

Дата: 9 сентября 2026 года.

## Реализация

В общем веб-интерфейсе при создании карты по источникам показаны вращающееся
кольцо с пульсирующей точкой, фактический этап обработки, номер текущей части
и время от сохранённого момента постановки задания в очередь. Процент готовности
не вычисляется: номер части обозначает текущий запрос, а не завершённую работу.
При отправке формы кнопка также показывает запуск и блокирует повторное нажатие.

После готовности спиннер сменяется галочкой и карта открывается в обзоре тем.
Отмена и ошибка останавливают анимацию. Сбой связи показан отдельно и запускает
повторное чтение состояния; временная ошибка загрузки готовой карты также допускает
повтор. Таймер продолжает отсчёт при повторном открытии; обновление каждую секунду
не попадает в live-объявления экранного диктора. Системная настройка
prefers-reduced-motion отключает движение. Миграция базы не требуется: API
возвращает существующее время created как created_at.

## Браузер

Изолированная SQLite-копия alpha20, localhost:18791, локальная тестовая модель
localhost:18921 с задержкой 45 секунд. Пользовательская база не изменялась.

1. Запущено создание по двум документам. Фаза «Выделяем темы · часть 1 из 1»,
   animationName=map-source-spin; матрица поворота меняется между наблюдениями.
2. Таймер показал 0:07 и 0:17; после выхода в библиотеку и возвращения — 0:33.
3. На ширине 1280 и 390 px нет горизонтального переполнения страницы;
   на 390 px ширина панели и её scrollWidth равны 374 px.
4. После окончания: «Карта готова», animationName=none, таймер скрыт,
   видны 4 из 10 узлов (корень и главные темы).
5. Второе создание отменено кнопкой: статус cancelled, анимация отсутствует,
   таймер скрыт, карта содержит только корень, доступно повторное создание.
6. Ошибок JavaScript в журнале нет. SQLite integrity_check — ok.
7. HTML, app.css и map-from-sources.js из итогового бинарника побайтно совпадают
   с исходными файлами. Тестовая вкладка и оба собственных процесса закрыты.

Сетевые сбои проверены автоматическими JS-сценариями, а reduced-motion —
проверкой CSS, без переключения системной настройки. Реальная модель и платные
провайдеры в этом прогоне не использовались.

## Сборка и установка

Все три Windows/amd64 бинарника собраны штатным скриптом и прошли version smoke
с единой версией 1.71.0-alpha.21. Артефакты и SHA256.json:
`build/web-alpha/alpha21/windows-amd64`.

Штатная установка в C:\Users\ZMII\bin заблокирована на проверке записи:
Access denied для .mem-deploy-probe-40b19a80382d402388a7ae420f10c47e.
При сборке в отдельный каталог скрипт выполнил тесты и сборку, затем остановился
из-за пользовательского процесса mem:19088 из C:\Users\ZMII\bin\mem.exe.
Процесс не останавливался. Три готовых файла из сохранённого временного stage
скопированы только в незанятый каталог артефактов проекта, SHA-256 совпали,
version smoke повторно успешен. Это подготовленная сборка, не установка в PATH.

На момент проверки все три установленные программы сообщают 1.71.0-alpha.20.
В рабочем окружении Go также сообщил о запрете записи telemetry upload.token
и module stat cache; эти предупреждения не помешали тестам, vet и сборке.

Чтобы установить из обычного PowerShell, завершите mem и запустите из корня
репозитория `./deploy/windows.ps1`, затем снова откройте `mem gui`.
