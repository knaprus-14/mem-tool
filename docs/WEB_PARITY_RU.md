# CLI и веб-интерфейс: текущая сверка и остаток

Сверка исходников: 11 сентября 2026 года, 1.71.0-alpha.33.
Основание — запрос о полноценном веб-интерфейсе со всеми прикладными возможностями
терминальной версии. Существующие редакторы карт сохраняются.

Это проверка доступных сценариев и конкретных отличий параметров по текущему коду.
Она не заменяет проверку каждого сценария в браузере и не объявляет полный паритет.
Старый рабочий список alpha.27 закрывал согласованный набор прикладных сценариев;
историческая матрица WEB_ROADMAP_RU.md отстала от реализации.

## Что доступно

| Семейство CLI | Веб-сценарий | Состояние / граница |
| --- | --- | --- |
| init, open, where, current | Создать, открыть, выбрать базу; локальный путь | Доступно; чужие серверные пути не принимаются |
| sources, show/get/view/source, stats | Документы, фрагменты, счётчики; статистика в настройках | Основной просмотр доступен; отдельный хронологический просмотр recent требует сверки |
| add, edit, delete/rm, retag, important | Заметки, корзина, история, свойства фрагмента | Доступно; формы не являются буквальными копиями всех CLI-флагов |
| import, import-status, import-runs/import-run | Загрузка файлов/папок, прогресс, страницы, ошибки, попытки, новые редакции | Доступно для PDF, DjVu, Markdown |
| add-file, index | Загрузка файлов/папок | Частично: .txt/.csv/.json из CLI index отсутствуют в веб-загрузке |
| search, ask | Поиск и ответы, выбор документа, теги/категория, даты, страницы, оценка, режим поиска | Доступно; веб-лимиты отличаются, контекст ответа задаётся в настройках |
| config | Настройки базы, разрешённые модели, проверка подключения, пересчёт векторов с применением/откатом | Доступно; произвольные адреса и секреты серверного режима задаёт администратор |
| mindmap create/list/show, templates, *-node, source-*, history, undo/redo, snapshots | Библиотека, редактор, источники, вложения, история, снимки | Доступно; предыдущий список «вложения впереди» устарел |
| mindmap ai-*, ask-branch, compare, study, export | Карта по источникам, AI-предложения, вопросы к ветви, сравнение, обучение, экспорт | Основные сценарии доступны; точный паритет произвольных CLI evidence-scope флагов ещё не подтверждён |
| map open | Граф знаний → Открыть граф | Работает существующий редактор в общей сессии, включая собственные инструменты и экспорт |
| map extract | Граф знаний → весь документ; Обслуживание базы → порция | В alpha.33 структура сохраняется до модели, результаты публикуются по окнам, незавершённые места повторяются отдельно |
| map build | Построение по найденным фрагментам с поисковыми фильтрами | Отдельной формы эквивалента CLI build нет; extract имеет другую семантику |
| map analyze, duplicates | Обслуживание базы → Фоновая обработка | Доступно; поиск дублей использует фиксированные ограничения |
| map coverage, status, diff, snapshots, corpus-diff, restore, restore-runs | Обслуживание базы → Проверки и история | Доступно; покрытие по документу также вынесено в новый раздел |
| map eval, eval-labeled, profile | Проверки и история → эталон/производительность | Доступно; profile фиксирует одну итерацию и не даёт выбрать именованный вид |
| map *-run/*-runs, reviews, edits, merges, approve-batch, merge-node, prune-runs | Проверки и история; загрузка плана с подтверждением | Доступно; лимиты списков и часть параметров фиксированы |
| help, version | Версия оболочки и пояснения в формах | Полной интерактивной справки по всем возможностям ещё нет |
| repl/TUI и оформление терминала | Терминал | Это отдельный способ управления, не веб-функция |
| mem-index, mem-bot | Отдельные программы | Веб-администрирование не включено в текущую оболочку |

## Добавлено в alpha.30

1. Раздел **Граф знаний**: загрузка файлов и папок через существующий импорт.
   После импорта документ появляется в выборе; импорт с ошибками виден отдельно.
2. **Построить / дополнить весь документ** запускает сохранённое фоновое задание.
   Оно последовательно обрабатывает порции по 16 пакетов до исчерпания новых
   фрагментов. Обработка выполняется на сервере и не зависит от открытой вкладки.
3. Есть отмена, продолжение, прогресс по фрагментам, покрытие и ссылка на редактор.
   Карточка документа открывает этот раздел с выбранным источником.
4. Отдельно показаны обработанные фрагменты, ссылки графа и пропущенные при импорте
   страницы. Отсутствие манифеста отмечается: полноту страниц тогда подтвердить нельзя.

Граф общий для базы: последовательный выбор разных документов дополняет его.
Автоматический запуск модели сразу после загрузки не выполняется: после импорта
пользователь выбирает источник и запускает построение. Пакеты сохраняются как
контрольные точки, порции публикуются по завершении. Через два часа можно продолжить
задание; после изменения настроек нужно создать новое. Уже обработанные либо
покрытые графом фрагменты повторно не генерируются.

## Обновление alpha.33

Полный документ сначала получает структуру с исходным текстом, затем смысловое
обогащение. Описание порций выше относится к alpha.30: в новом полном режиме
публикация выполняется по готовности каждого окна. Ошибки модели оставляют
видимое незавершённое место, не блокируя остальные. При повторе сохраняются
успешные окна и ручные правки. Добавлен CLI-флаг `--all-chunks` с тем же механизмом.

Импорт DOCX/TXT/CSV/TSV/JSON/XML реализован через общий ingestion и очередь веба,
проверены полный путь очереди с тестовой моделью embeddings, исходный текст,
отсутствие выдуманных страниц и диагностика непригодных файлов. DOCX не выполняет
OCR изображений и не назначает физические номера страниц.

## Конкретная оставшаяся работа

- [x] **Импорт остальных форматов CLI:** TXT/CSV/JSON и дополнительно TSV/XML/DOCX;
  общий extractor, очередь, provenance и тесты обработки добавлены в alpha.33.
- [ ] **Форма `map build`:** поисковый фокус, число фрагментов, фильтры и контекст;
  ясно отличать выборку из поиска от полного последовательного разбора документа.
- [ ] **Область и план `map extract`:** физические страницы и тег, предпросмотр
  плана без модели (`--dry-run`). Для coverage также нужны страницы и тег.
- [ ] **Расширенные параметры обслуживания:** iterations/view для profile,
  threshold/kind/nodes/limit для duplicates, лимиты/фильтры истории, keep и точный
  срок для prune-runs. Сейчас форма фиксирует часть значений в коде.
- [ ] **Окончательная сверка остальных CLI-параметров:** evidence-scope AI-карт,
  recent и общая справка. Зафиксировать по каждому параметру: доступен в форме,
  намеренно ограничен веб-средой или требует реализации, затем проверить сценарий.
- [ ] **Проверка целевого размещения:** установка текущей версии в PATH, VDS/HTTPS,
  запуск и восстановление на реальном сервере. Локальные тесты этого не доказывают.

Публичная регистрация, SSO, биллинг, совместные роли, двусторонняя синхронизация
и веб-управление mem-index/Telegram-ботом — отдельные расширения, а не скрыто
выполненные пункты первого веб-выпуска.

## Основания в коде

- `cmd/mem/usage.go`, `cmd/mem/commands_map.go`: текущий контракт команд и параметров.
- `internal/webapp/assets/app.js`, `index.html`: библиотека, импорт, поиск, настройки.
- `internal/webapp/assets/graph-documents.js`: новый сценарий документа и графа.
- `internal/webapp/assets/operations.js`, `internal/webapp/maintenance.go`:
  формы обслуживания и фактически передаваемые параметры.
- `pkg/mem/web_operations.go`, `web_graph_operations.go`: сохранённые задания,
  ограничения, полный разбор и продолжение.
- `internal/webapp/graph.go`: подключение существующего редактора графа.
