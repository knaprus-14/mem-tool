# Проверка веб-интерфейса 1.71.0-alpha.3

Дата: 9 сентября 2026 года. Продолжение этапа 2: выбор папки и обновление
управляемого веб-документа новой редакцией. Старые редакторы карт не изменялись.

## Поведение и автоматические проверки

- `go test ./... -count=1 -timeout=300s` через `deploy/windows.ps1` — успешно.
- `go vet ./...`, затем повторная проверка затронутых web-пакетов — успешно.
- `node --check internal/webapp/assets/app.js` — успешно.
- `git diff --check` — без ошибок; предупреждения о нормализации окончаний строк
  в ранее изменённых файлах не являются ошибками проверки.

Изолированные Go/HTTP-тесты с временными базами и тестовым сервисом векторов:

- новая редакция меняет текущий файл, сохраняя ID документа и существующих
  фрагментов; в библиотеке остаётся один документ;
- предыдущий оригинал сохраняется, история содержит снимок прежнего состояния
  и путь к прежнему файлу;
- CLI-импорт удержанного старого оригинала не создаёт вторую текущую копию
  одного управляемого документа;
- одинаковый текущий файл возвращает существующее задание; исторические байты
  можно явно загрузить новой редакцией после последующего изменения;
- изменение тегов после предварительной проверки, перед записью документа,
  вызывает конфликт; текущее содержимое, теги и история не перезаписываются;
- устаревшее задание отклоняется до запроса векторов, ошибка обработки сохраняет
  текущую редакцию; внутренние сообщения модели не передаются клиенту;
- после сбоя между записью редакции и завершением задания результат восстанавливается
  по журналу импорта без повторной векторизации;
- одинаковые имена в разных папках сохраняют отдельные источники; относительные
  подписи с обходом каталогов, абсолютными путями или управляющими символами отклоняются;
- HTTP preview → upload → worker → библиотека, отказ устаревшему состоянию (409),
  чужому владельцу (404), анонимному запросу (401) и неверному CSRF (403);
- просмотр очереди схемы 1 без миграции; переход на схему 2 с сохранением задания,
  оригинала и его идентичности; отказ неизвестной будущей схеме.

Новые сценарии извлечения проверены на Markdown. Отдельные живые импорты PDF/DjVu
и внешние модели в этом этапе не запускались; используются прежние общие импортёры.

## Браузер

Изолированный локальный сервер на порту 18767, отдельный каталог состояния
`build/web-alpha/alpha3/smoke-state`. Проверены создание пустой базы, открытие формы,
переключение «Отдельные файлы» / «Папку с документами», блокировка отправки без
выбранных файлов. При viewport 390 px ширина содержимого диалога и scrollWidth
равны 343 px: горизонтального переполнения нет. Журнал ошибок JavaScript пуст.
Временный сервер остановлен, вкладка закрыта, размер окна сброшен.

Выбор файлов, отправка браузерной формы, список выбранных файлов и форма обновления
реального документа не проверялись через браузер: ранее автоматическая проверка
разрешений отклонила передачу файлов на localhost. Этот отказ не повторяли и не
обходили. Изменение документов подтверждено изолированными Go/HTTP-тестами выше.

## Артефакты и установка

`deploy/windows.ps1 -Target ./build/web-alpha/windows-amd64` выполнил общие тесты,
сборку трёх Windows/amd64 программ и smoke-проверку единой версии alpha.3. После
этого скрипт остановился до копирования, обнаружив запущенный пользовательский
`mem` из `C:\Users\ZMII\bin` (PID 26852 на момент проверки). Этот процесс не останавливали.

ранее пустую папку `build/web-alpha/alpha3/windows-amd64`. Сверены SHA-256 источника
и копии, команды `version` всех трёх программ. Это артефакты для проверки, а не
обновлённая установка PATH. Результат — `verification.json` рядом с программами.

Для ручной установки после остановки работающих mem-процессов, из обычного PowerShell:

```powershell
Set-Location C:\Users\ZMII\Documents\ChatGPT\mem-tool
.\deploy\windows.ps1
mem version
mem-index version
mem-bot version
```

До первого запуска новой версии с существующей очередью сохраните согласованную
копию всей `.mem` при остановленных писателях: схема очереди 2 не открывается alpha.2.
Полный перенос путей, истории и карт между компьютерами остаётся отдельной работой.
