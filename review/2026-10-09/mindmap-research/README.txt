MEM-TOOL: ИССЛЕДОВАНИЕ КАРТ МЫСЛЕЙ, 09.10.2026

Начать: REPORT_RU.html. Работает локально без сервера и внешних библиотек.
В конце отчёта — поиск и фильтры каталога 120 функций; щелчок раскрывает
текущую реализацию, предложение, приёмку, зависимости и основания.

REPORT_RU.md — полный редактируемый текст для чтения и дальнейшей работы.
features.json — исходный структурированный backlog, features.csv — таблица
с разделителем ; и UTF-8 BOM для импорта в табличные редакторы.

Приложения: classic-audit.html, graph-audit.html, learning-research.html.
Рядом сохранены их Markdown-исходники и два реестра источников JSON.
Для переноса отчёта копируйте всю папку. Ссылки на код сработают только там,
где имеется репозиторий по исходному абсолютному пути. Внешние научные
и продуктовые страницы требуют сети; текст отчёта самодостаточен.

Пересборка (без установки пакетов): node build-report.cjs
Требуется установленный marked из bundled Codex Node modules. Другой путь
можно задать переменной MEM_REPORT_NODE_MODULES. Не использовать node build
для сборки приложения: данный скрипт только собирает исследовательский пакет.
Исходные части для пересборки: report-introduction.md, current-state.md,
architecture-roadmap.md, три audit/research.md и features.json.
При пересборке REPORT_RU.md и HTML/CSV/verification.json генерируются заново.

Воспроизведение дефекта: document_ledger_probe_test.go.txt и Go overlay.
Тест использует временную базу и fake provider, штатные исходники не меняет.
Пути overlay абсолютные для этой рабочей копии. Вывод сохранён отдельно.
В выводе есть отказ записи Go telemetry upload.token; он не остановил тест.
Итоговый FAIL — ожидаемое нарушение проверяемого инварианта актуальности.
Этот исследовательский тест не включён в штатный test suite и не чинит дефект.

verification.json фиксирует структуру каталога и неизменность снимка 185
исходных файлов. Дополнительная проверка интерфейса отчёта описана в QA.json.
Это проверка артефакта исследования, а не работоспособности приложения,
обучающей эффективности или установленного релиза.
