# Проверка 1.71.0-alpha.17 — 2026-09-09

## Реализовано

В общем веб-интерфейсе добавлены перемещение/порядок ветвей, поиск родителя
по названию и пути, оба режима удаления, тип и блокировка узла, метаданные
и архив карты, фрагменты базы и URL-источники, порядок/удаление привязок,
снимки и экспорт во все восемь форматов CLI. Прежние редакторы сохранены.
Действия вызывают общие транзакции ядра; история, ревизия и квитанция повтора
фиксируются атомарно. Снимок не меняет ревизию карты.

Для VDS подготовлены nginx HTTPS, административные offline backup/verify/restore,
скрипт остановки/возврата службы и systemd-таймер. Это аварийное восстановление
с прежними абсолютными путями, не перенос Windows → Linux.

## Автоматические проверки

- `go test ./... -count=1 -timeout=300s` — прошёл через `deploy/windows.ps1`.
- `go vet ./...` — прошёл.
- Целевые проверки классических карт и новых веб-сервисов — прошли.
- HTTP-сценарий новых действий, включая снимки: владелец, анонимный запрос,
  CSRF, неизвестные поля, устаревший экспорт и фактические изменения — прошёл.
- `node internal/webapp/map_layout_test.cjs` — 10/10, включая поиск родителей,
  исключение собственной ветви и заблокированного родителя.
- `node --check` для обновлённых JS-модулей — прошёл.
- `python deploy/web_backup_test.py` — 4/4: копия/восстановление, committed WAL,
  запрет перезаписи, повреждение SHA-256, лишние/повторяющиеся пути, плохая SQLite.
- `git diff --check` — прошёл; Git предупреждает о настроенной нормализации EOL.

Тесты ядра проверяют перемещение и порядок, удаление с переносом детей,
восстановление ветви и источников, блокировку/разблокировку, чужие ID/псевдонимы,
старую ревизию, повтор с другим содержимым/actor, откат при сбое квитанции,
источники с устаревшим pin, все форматы экспорта и скрытие путей в серверном режиме.

Первый запуск Python-тестов упёрся в недоступные временные каталоги для
ограниченного токена Windows. В Windows вспомогательный код теперь наследует
ACL родителя, в POSIX использует 0700; существующие ACL не изменялись.
SQLite-соединения закрываются явно. Оставшиеся неудачные тестовые каталоги
изолированы под игнорируемым `build/web-alpha/_recovery-tests`; рабочие данные
пользователя не затронуты.

## Браузер

Встроенный браузер, `http://127.0.0.1:18778/`, изолированная копия искусственной
карты из alpha.13. Обычная ширина 1280×720 и мобильная 390×844.

Проверены:

1. Создание тестовой ветви и перенос в начало «Темы 2».
2. Тип «Задача», блокировка кнопок изменения/перемещения/удаления и разблокировка.
3. Добавление URL с буквальным `<script>` в названии: вывод как текст.
4. Снимок «Перед проверкой удаления» на ревизии 11 без изменения ревизии.
5. Удаление ветви и восстановление через историю вместе с URL-источником.
6. Поиск восстановленного узла, поиск нового родителя по части пути, отсутствие
   результатов с отключённым сохранением; форма шириной 360 px при экране 390 px.
7. Неактивные «Выше/Ниже» у единственного источника.
8. PNG большой карты возвращает понятный отказ; индикатор подготовки завершается.
   SVG всей карты передан браузеру для сохранения. Содержимое всех восьми форматов
   дополнительно проверено Go-тестами; сохранение файла в пользовательскую папку
   загрузок отдельно не утверждается.
9. Изменение названия и статуса карты, возврат к основным темам.

В журнале браузера ошибок JS нет. Тестовая вкладка закрыта, обычная ширина
восстановлена. Остановлены только свои процессы с проверкой абсолютного пути exe.

Финальное состояние fixture: `PRAGMA integrity_check = ok`, карта
«Проверенная карта — 588 узлов», статус ready, ревизия 14; созданная тестовая
ветвь под `topic-1`, тип task, защита снята; один URL-источник и один снимок.
