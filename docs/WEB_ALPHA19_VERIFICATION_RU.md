# Проверка 1.71.0-alpha.19

Дата: 9 сентября 2026 года. Проверки выполнялись на отдельных временных базах
и в `build/web-alpha/alpha19/fixture`. Рабочие документы пользователя не менялись.

## Реализовано

- AI-предложения для классических карт: расширение ветви, дополнение текста,
  подбор источников; очередь, отмена, сохранённый предпросмотр, выбор отдельных
  предложений и публикация через общую транзакцию CLI.
- Проверка ревизии карты, состояния источников и настроек перед генерацией;
  повторная проверка источников перед публикацией. Повтор одного запроса
  возвращает его квитанцию. Сбой записи квитанции откатывает публикацию целиком.
- Отмена генерации прерывает запрос модели. Перезапуск восстанавливает уже
  записанный предпросмотр; прерванное обращение к модели автоматически не повторяется.
- Копирование карты с независимыми ID узлов и источников, собственной историей,
  снимком и статусом черновика. Сами документы не дублируются.
- История попыток веб-импорта; итог записи документа и страницы по 50 записей,
  текст/OCR, уверенность OCR, пустые/пропущенные страницы и признаки предупреждений.
  Отчёт выбирается через квитанцию задания владельца, без произвольного run ID.

Существующие команды CLI/TUI и самостоятельные редакторы карт сохранены.
В alpha.18 этого же цикла были добавлены учебные карточки, сравнение карт,
ответы по источникам ветви, проверка моделей, предпросмотр разбиения и фоновое
поколение векторов с атомарным применением/возвратом. Подробности:
[проверка alpha.18](WEB_ALPHA18_VERIFICATION_RU.md).

## Автоматическая проверка

- `go vet ./...` — прошёл.
- `node internal/webapp/map_layout_test.cjs` — 10 из 10.
- Синтаксис новых JS-модулей и `app.js` проверен `node --check`.
- `git diff --check` — ошибок форматирования нет; имеются обычные предупреждения
  Git о переводах строк LF/CRLF.
- Новые тесты проверяют все три AI-действия, непубликующий предпросмотр, выбор
  родителя/потомка, повтор, отмену, прерывание модели, устаревшие источники,
  восстановление после сбоя, предел токенов и атомарный откат при сбое квитанции.
- Копирование проверено на независимость ID и последующих правок, повтор запроса
  и отклонение устаревшей ревизии.
- История импорта проверена на реальном HTTP-импорте Markdown и на отдельном
  журнале из 121 страницы: границы 50/50/21, пустые/ошибочные страницы, сохранение
  старого отчёта после новой попытки и отсутствие путей/текстов ошибок в API.
- HTTP-проверки включают владельцев, анонимный доступ, CSRF, неизвестные поля
  запросов и недопустимые параметры истории.

## Проверка браузером

Локальный сервер собран из исходников, модель заменена управляемым HTTP-сервисом.
Это проверка протокола и поведения, а не качества ответов настоящей модели.

1. Из карты с 588 узлами создана независимая копия. Исходная карта осталась
   на ревизии 15; копия начала свою историю с ревизии 1.
2. Получен предпросмотр из двух связанных предложений. Снята отметка дочернего,
   применён только родитель: на карте стало 589 узлов. Текст `<script>` показан
   буквально; в диалоге нет созданных из него элементов `script`.
3. Через историю публикация отменена и возвращена. Ревизии копии: 2 → 3 → 4.
4. Другое задание сохранено, диалог закрыт и снова открыт, затем задание отменено.
   В очереди и общем журнале AI подтверждён статус `cancelled`.
5. Реальный веб-импорт `history-check.md` завершён с одним фрагментом. В браузере
   показаны попытка, время и итог записи; отсутствие физических страниц Markdown
   объяснено отдельно.
6. Для UI длинного отчёта в изолированную базу добавлена синтетическая вторая
   попытка на 121 страницу. Проверены 1–50, 51–100, 101–121, скрытие кнопки
   следующей страницы в конце и возврат к началу. Это не OCR реального PDF.
7. На ширине 390 px диалог AI: внешняя ширина 358 px, внутренняя/scrollWidth
   341/341; история импорта: 343/343. Горизонтального переполнения нет.
8. Журнал ошибок JavaScript пуст. SQLite `integrity_check` вернул `ok`.

Последняя правка после браузерных сценариев — доступное название диалога истории
через `aria-labelledby`; она включена в финальную пересборку.
Все тестовые серверы и вкладки, открытые этой проверкой, остановлены/закрыты.

## Сборка и установка

`deploy/windows.ps1 -Target build/web-alpha/alpha19/windows-amd64` собрал все
три Windows/amd64 программы, проверил версии и совпадение SHA-256 после копирования.
Контрольные суммы находятся рядом с файлами в `SHA256.json`.
Linux/amd64 `mem` также собран с `CGO_ENABLED=0`.

**Это артефакты в проекте, а не установка в PATH.** Обычный запуск deployment
остановлен на предварительной проверке доступа:

```text
Deployment target 'C:\Users\ZMII\bin' is not writable.
Access to ...\.mem-deploy-probe-887644e099f443a3acc229402519fe85 is denied.
```

Фактически установленные `mem`, `mem-index`, `mem-bot` проверены: **alpha.17**.
Для установки требуется запуск `./deploy/windows.ps1` из обычного PowerShell
с правом записи в этот каталог. Другие файлы каталога установки не затрагиваются.

Go выводил предупреждения об отказе записи в пользовательский telemetry/mod-cache;
при локальном `GOCACHE`, `GOPROXY=off` и уже установленных зависимостях тесты,
vet и сборки завершились успешно. Новые зависимости не устанавливались.

## Границы результата

Полного паритета со всеми командами программы ещё нет. Остаются семейство
расширенного графа, управляемые файловые вложения и ссылки на граф, метаданные
документных фрагментов, перенос базы с историей и путями между Windows/Linux,
общие дисковые квоты и пересоздание границ фрагментов всей базы.
Alpha.18 пересчитывает векторы существующих фрагментов, не их границы.

AI ограничен 30 источниками / 60 000 символов на задание, 180 секундами на
задание и 4096 токенами одного ответа. Очистка сохранённых AI-заданий через GUI
пока не подключена; действуют ограничения хранения. Классическая карта в вебе
ограничена 1000 узлами / 4 МиБ. Конкурентная модель нескольких пользователей,
платные провайдеры и высокая нагрузка этим прогоном не проверялись.

Linux runtime/VDS/HTTPS smoke не выполнен: WSL в этой среде возвращает
`Wsl/EnumerateDistros/Service/E_ACCESSDENIED`, доступа к целевому VDS в задаче нет.
Linux-сборка не означает развёрнутый сервис. Race detector не запускался.
