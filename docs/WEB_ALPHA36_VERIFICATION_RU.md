# Проверка alpha.36 — оригинальные формулы PDF

## Причина и результат

На копии базы `E:\temp\mem-test5` найден узел
`kn-df590df0e517a1eb76aae378eb0b6dd0`, «Определение расстояния между ПК по формуле».
Его evidence указывает на физическую страницу 15 SP10.pdf. В исходном PDF
визуально присутствуют корни, дробь и степени; импортированный текст потерял
математическое расположение. Это повреждение текстового извлечения, которое
нельзя надёжно исправить простым форматированием или по вектору.

Карточка теперь показывает оригинальную страницу PDF. Изображение увеличивается;
мышью или числовыми границами можно выбрать область формулы и вставить её в
карточку. Сохранённая строка не меняется и доступна в раскрывающемся блоке.
Та же функция работает для любой PDF-цитаты через «Источники» и окно сверки,
в том числе для таблиц и схем.

## Реализация и границы

- `pkg/ingest/pdf_preview.go`: рендер одной физической страницы, до 2000 пикселей
  по длинной стороне; pdftoppm, mutool или Python с PyMuPDF из конфигурации
  импорта / переменных окружения / PATH. Загрузка зависимостей не выполняется.
- `format=png` в существующем `/api/source`: прежняя авторизация, разрешение
  citation через актуальный evidence, проверка отпечатка и рендер частного
  snapshot. Путь и номер страницы из запроса не используются.
- Два рендера одновременно, дедлайн 30 секунд, ограничение PNG 20 MiB,
  удаление временных файлов; занятая очередь и ошибка рендера возвращают
  429/422 с возможностью повторить просмотр. Подмена источника возвращает 409.
- Границы выделения хранятся в `sessionStorage` этой вкладки, отдельно для
  документа, редакции, страницы и evidence. Они не меняют текст или граф в БД.
- Исходный PDF нужен для просмотра. Изображения и границы не встраиваются
  в автономный экспорт HTML. Математическая транскрипция LaTeX/MathML по OCR
  не создаётся; изображение не объявляется автоматически проверенной формулой.
- Уверенность извлечения остаётся оценкой модели для узла, а не доказательством
  правильности формулы. Автопоказ включается для узлов formula и упоминаний
  формул/уравнений в названии или тексте; для остальных PDF есть ручная кнопка.

## Проверки

- Финальный `go test ./... -count=1 -timeout=300s` завершился успешно для
  всех пакетов; пакет `pkg/mem` прошёл за 61.066 секунды.
- Go: тесты рендера проверяют выбранную страницу, таймаут, очистку временного
  каталога, отмену и отбраковку некорректного PNG.
- HTTP: проверены отсутствие сессии, неизвестная citation, игнорирование
  подставных path/page, рендер именно проверенного snapshot, отказ после
  изменения PDF, ограничение параллельности и ошибка рендера.
- JavaScript: распознавание формулы внутри constraint, границы области,
  разделение выделений разных цитат и редакций. Регрессии тематических групп
  также прошли (приватные тесты корпуса в этом запуске пропущены).
- `go vet ./...`, дополнительный `go vet ./pkg/mem` после правки обработки
  отсутствующей конфигурации; `git diff --check`.
- В браузере на копии базы: `mem map open`, затем общий `mem gui` и его
  встроенный граф. Изображение страницы 15 загружается в обоих маршрутах;
  консоль встроенного графа без ошибок.
- Проверены ввод границ 24/80/96/91%, вставка области, восстановление после
  обновления страницы, выделение мышью и узкий экран 390 × 844. Временная
  настройка размера браузера сброшена.

Оригинальная БД открывалась только read-only для SQLite backup. Рабочая копия:
`build/web-alpha/alpha36/repro`. Исходный PDF читался без изменения.
Новая обработка моделью и импорт не запускались.
