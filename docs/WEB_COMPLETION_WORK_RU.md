# Завершение веб-интерфейса — рабочий список

Основание: запрос Руслана от 10.09.2026 завершить остаток без дополнительных вопросов.
Исходное состояние: 1.71.0-alpha.26; существующие изменения и данные сохраняются.

Проверить и подключить оставшиеся прикладные сценарии:

- [x] Корзина карт, восстановление, повторное удаление.
- [x] Метаданные документов и расширенная статистика.
- [x] Вложения и ссылки на узлы графа.
- [x] Расширенный граф и его операции в общем веб-интерфейсе.
- [x] Пересоздание фрагментов документов.
- [x] Перенос базы с оригиналами, картами и историей.
- [x] Учёт и ограничение дискового пространства.
- [x] Актуальная матрица возможностей, документация и проверки.
- [x] Общие тесты, сборка трёх Windows-команд и попытка установки.

Внешние условия: доступ к VDS не предоставлен; установка в защищённый bin
проверяется отдельно. Публичная регистрация, SSO, биллинг и двусторонняя
синхронизация баз не входят в согласованный первый веб-выпуск.


Результат: 1.71.0-alpha.27. [Руководство](WEB_COMPLETION_RU.md),
[проверки и ограничения](WEB_ALPHA27_VERIFICATION_RU.md).
Пункт установки означает выполненную попытку: PATH остался alpha.25 из-за
запрета записи в bin и работающих пользовательских процессов. Windows-артефакты
подготовлены отдельно; для mem serve подготовлена Linux/amd64 сборка без runtime-проверки.

## Уточнение 11.09.2026 — alpha.30

Закрытые пункты выше относятся к alpha.27. Они не подтверждают полный паритет
каждого CLI-параметра. Актуальная сверка и незакрытые задачи:
[WEB_PARITY_RU.md](WEB_PARITY_RU.md). В alpha.30 добавлен отдельный сценарий полного
документа в графе с загрузкой, выбором, автоматическим продолжением порций и покрытием.
