# Проверка 1.71.0-alpha.34 — темы и связи

Дата: 2026-09-11. Изменение продолжает предварительный MINOR-релиз 1.71.0.

## Причина дефекта

Прежний алгоритм делал документ одним из центров кластеризации и обходил все
типы связей. После полного импорта служебные `derived_from` и `contains` стягивали
знания в кластер исходного PDF. Фокус размещал сотни узлов в трёх вертикальных
столбцах с минимальным шагом 46 пикселей и масштабом 1, обрезая результат.

## Изменение

- Тематические группы строятся по существующим смысловым связям, без документа
  и служебных ссылок на источник. Одинаковые названия тем группируются для
  просмотра; исходные узлы, требования, цитаты и рёбра сохраняются отдельно.
- Большие старые карты открываются в режиме «Темы и связи». Обзор, поиск,
  карточки темы, связи с другими темами и исходные цитаты работают в прежнем
  редакторе. Пагинация ограничивает число карточек на странице до 24.
- «Без тематических связей» и «Источники и фрагменты» доступны отдельно.
  Число содержательных и служебных связей показано раздельно.
- Подробный граф сохранён. Фокус использует строки с переносом и вписывание,
  служебные ссылки не участвуют в силовой раскладке. Линза «Все» и выбор узла
  позволяют просматривать исходные связи.
- Сохранённые виды 1–9 читаются, новые записываются с версией 10.
- В запросе модели уточнены язык и названия тем, исключены дубли входного
  документа, запрошены только подтверждённые связи с темами. Проверка цитат
  и идентичность прежних контрольных точек не изменены.

## Проверки

1. `go test ./... -count=1 -timeout=300s` — успешно, пакет mem 65 с.
2. `go vet ./...` — успешно.
3. После завершающих правок интерфейса повторены тесты HTML, тем и совместимости
   видов: `go test ./pkg/mem -run 'TestKnowledge(MapHTML|Topics|MapLayout|MapView)'`.
4. `node pkg/mem/web/knowledgeTopics.test.cjs` с приватным JSON снимка — 6/6:
   исключение документного центра, сохранность разных требований и цитат,
   идентичность межтематических связей, несвязанные и пустые графы, раскладка
   611 узлов, полное распределение узлов реального корпуса.
5. Встроенный браузер: обзор; тема «Трубопроводы», 13 узлов; текст требования
   «Монтаж стальных труб» вместе с исключением и двумя цитатами физической
   страницы 34; подробный граф; поиск; межтематические переходы; страницы
   обзора; группа из 95 узлов, четыре страницы; источники, семь страниц.
   Проверены ширины 1440 и 390. На узком экране ширина содержимого равна
   доступной ширине 375 пикселей. Ошибок JavaScript не обнаружено.
6. `git diff --check` — успешно, предупреждения только о преобразовании CRLF/LF.

Реальный корпус читался через SQLite backup в рабочую копию
`build/web-alpha/alpha34/repro`. В копии 635 узлов и 960 рёбер: 285 связей между
знаниями и 675 служебных связей. Получены 132 группы знаний (101 с названием
извлечённой темы/раздела, 31 группа связанных узлов), отдельно 95 узлов без
тематических связей и 147 узлов источников. Все объекты сохранены.
Это более поздний снимок, чем приложенный скриншот с 627 узлами.

Предпросмотр: `build/web-alpha/alpha34/preview/index.html` — автономный HTML
с приватным снимком, не предназначен для публикации. Модель повторно не
запускалась. Английские названия, ошибки содержания и пробелы прошлой генерации
автоматически не переписаны; тесты не доказывают полноту смыслового разбора.
Открытие PDF через серверный обработчик в автономном предпросмотре недоступно.

Все три программы собраны для windows/amd64 в
`build/web-alpha/alpha34/bin`, команды `version` подтверждают alpha.34.

| mem-index.exe | 305D990C4A3AF4BB52AA08FF071BDC25DC2D1ACB889F446FD488571FF7799558 |

`deploy/windows.ps1` остановился на проверке доступа к `C:\Users\ZMII\bin`:
`Deployment target ... is not writable`, `Access to the path ... is denied`.
Установка не выполнена; установленный `mem.exe` по-прежнему alpha.33.
Сборка использовала разрешённый GOCACHE. Предупреждения Go о недоступном
telemetry/upload.token и stat cache не помешали тестам и сборке.
Отдельный запуск headless Playwright из оболочки был запрещён (`spawn EPERM`);
браузерная проверка проведена доступным встроенным браузером.

Для установки из обычного PowerShell с правом записи в каталог бинарников
остановить работающий `mem gui`, затем выполнить:

```powershell
& "C:\Users\ZMII\Documents\ChatGPT\mem-tool\deploy\windows.ps1"
mem version
mem --dir "E:\temp\mem-test5" gui
```
